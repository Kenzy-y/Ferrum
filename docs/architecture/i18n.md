# Localization

Crate `i18n` (core layer, no GPUI).

**Purpose.** All user-visible strings, via Fluent.

**Key types.**
- `I18n` — bundles for one locale plus the `en` fallback; `text(id)`,
  `text_with(id, args)`. A missing message logs a warning and shows its id.
- `resolve_locale(configured, system)` — configured language, else the system
  language if available, else `en`; matched by language subtag.
- `LocalizationSettings` — `[localization] language = "ru"`.

**Files.** `crates/i18n/locales/<locale>/*.ftl`, embedded with `include_str!`.
The product name is the `-product-name` term injected from `app_identity`;
never write it in `.ftl` files. Unicode isolation marks are disabled until
the text renderer handles them.

**Extending.** New strings: add the same id to every locale (a test enforces
it). New locale: add the folder, list it in `AVAILABLE_LOCALES` and in
`sources()`.
