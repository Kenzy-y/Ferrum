# 0009. Инлайн-подсказки, code lens и панель Problems

**Дата:** 2026-11-07. **Статус:** оформление подсказок и списка мест ждёт согласования владельцем.

## Контекст

Этап 4: инлайн-подсказки и code lens от rust-analyzer, панель Problems и счётчики в статус-баре. В `editor.svg` есть линза «1 implementation» в конце строки и счётчики «0 errors / 0 warnings» с галочкой. Инлайн-подсказок, списка мест и содержимого панели Problems в макетах нет.

## Решение

- **Подсказки** рисуются внутри строки шрифтом кода того же размера цветом `syntax.inlay_hint`. Уменьшенный шрифт, как в витрине компонентов, потребовал бы раскладывать строку по частям, а моноширинная сетка и попадание мышью держатся на одной раскладке. Курсор в позиции подсказки стоит перед ней, клик по подсказке ставит курсор в её позицию. Строки длиннее `LONG_LINE_CHARS` показываются без подсказок.
- **Линзы** стоят в конце строки, как в макете: шрифт кода `font_size.xs`, цвет `syntax.inlay_hint`, отступ `code_lens.gap` (60 px из макета). Показываются только линзы, по которым IDE умеет действовать (`LensAction::ShowLocations`). Run и Debug ждут терминала и отладчика. Клик по линзе с одним местом переходит туда, с несколькими открывает список мест в стиле списка дополнений.
- **Запросы.** Подсказки запрашиваются для видимых строк и одного экрана сверху и снизу, линзы — для всего документа. Запрос уходит через `[editor] language_decorations_delay_ms` (150 мс) после правки или прокрутки, а также по refresh от сервера и при переходе сервера в Ready. Неудачный запрос не повторяется до следующей правки, поэтому сбойный сервер не нагружает CPU в простое. Включение и выключение: `[editor] inlay_hints`, `[editor] code_lens`.
- **rust-analyzer** получает `experimental.commands = ["rust-analyzer.showReferences"]`, иначе он отдаёт линзы без команды.
- **Problems.** Модель и вид лежат в `workbench` (`contrib/problems`). Shell передаёт туда диагностики каждого запущенного сервера по всем файлам, а не только по открытым. Подсказки (severity Hint) в список не попадают. Счётчик на вкладке показывает число проблем. В статус-баре ошибки и предупреждения, при нуле ошибок галочка `icon.success` (`#9DADA1` из макета), иначе `CircleX` цвета `diagnostic.error`.
- Новые иконки Lucide: `circle-x`, `info`.

## Последствия

- `workbench` теперь зависит от крейта `language` (внутренняя зависимость).
- Для светлой и контрастной тем нужно задать `icon.success`.
