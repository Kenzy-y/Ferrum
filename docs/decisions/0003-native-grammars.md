# 0003. Нативные грамматики tree-sitter до появления плагинов

**Дата:** 2026-11-04. **Статус:** принято владельцем.

## Контекст

По AGENTS.md грамматики приходят из плагинов как wasm, но плагины — этап 9, а подсветка нужна на этапе 3. Фича `wasm` у `tree-sitter` тянет свою версию `wasmtime`, которая может не совпасть с версией для `extension_host`.

## Решение

- Встроенные языковые пакеты подключают нативные крейты грамматик (`tree-sitter-rust`, `tree-sitter-toml-ng`, MIT) и регистрируют их в `syntax::GrammarRegistry`. Wasm-грамматики плагинов позже пойдут через тот же реестр.
- Крейт `lang_rust` создан сейчас, только с декларативной частью (расширения, грамматика, запросы). Часть rust-analyzer добавится на этапе 4.
- Крейт `lang_toml` — отдельный декларативный пакет: проверка, что язык добавляется без правок ядра. Правки понадобились только в `ferrum` (одна строка регистрации и зависимость).
- Запросы подсветки и outline — свои. Основой можно брать только запросы из самих крейтов грамматик, не из Zed, Helix, nvim-treesitter.
- Зависимости согласованы: `tree-sitter`, `tree-sitter-rust`, `tree-sitter-toml-ng`, `streaming-iterator`.

## Последствия

- Для сборки нужен C-компилятор (грамматики — C-код). `.cargo/config.toml` задаёт `CFLAGS=-DTREE_SITTER_HIDE_SYMBOLS`, иначе на Windows линковщик пишет предупреждение об экспорте, а `-D warnings` делает его ошибкой.
- Версия `tree-sitter` закреплена через `=`. Обновлять её вместе с крейтами грамматик, отдельным коммитом.
