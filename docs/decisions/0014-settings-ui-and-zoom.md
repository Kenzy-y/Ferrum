# 0014. UI настроек, масштаб интерфейса, запись файлов настроек

**Дата:** 2026-11-10. **Статус:** принято владельцем (выбор вариантов в чате).

## Контекст

Владелец попросил закрыть этапы 4–5 и сделать UI настроек (было в этапе 10). Макета страницы настроек нет. Для правок из UI нужно писать `settings.toml`, не теряя комментарии пользователя.

## Решение

- **Запись TOML** — новая зависимость `toml_edit` (MIT/Apache, уже была в дереве транзитивно): `settings::edit::set_value` меняет одно значение, сохраняя комментарии и порядок; пустые таблицы после удаления убираются.
- **Поля из схемы** — `SettingsRegistry::fields(namespace)`: ключ, doc-комментарий, вид (переключатель, число, текст, выбор, список строк, «только в TOML») и значение по умолчанию. `serde_json` включён с `preserve_order`, чтобы поля шли в порядке объявления.
- **Страница настроек** — вкладка в области редактора, оформление как у страницы плагина: поиск, слева пространства имён, справа поля, переключатель «Пользователь / Рабочая область», «Сбросить» у изменённых, вкладка «Сочетания клавиш» (запись нажатия, удаление; отключение встроенной привязки — пустая команда в `keymap.toml`). Шестерёнка и Ctrl , открывают страницу; файлы — командами `preferences.openSettingsFile` и `preferences.openKeymap`.
- **Масштаб** — `[appearance] zoom` (0.5–2.0, шаг 0.1): все токены метрик умножаются на масштаб, rem gpui-component следует за размером шрифта. Ctrl = / Ctrl Shift = / Ctrl − / Ctrl 0, значение пишется в пользовательский `settings.toml`.
- **Разделение редактора** — две группы рядом, у каждой свои вкладки, без перетаскивания вкладок между группами.

## Последствия

- Описания настроек пока на английском (doc-комментарии); перевод схемы — отдельная задача.
- Список полей не виртуализирован: их десятки, а не тысячи; список сочетаний виртуализирован.
- В debug-сборках `FERRUM_DEBUG_COMMANDS` запускает команды при старте — для скриншотов при разработке.
