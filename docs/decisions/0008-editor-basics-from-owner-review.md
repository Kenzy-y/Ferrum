# 0008. Пропущенные основы редактора: пары, сниппеты, меню, настройки

**Дата:** 2026-11-05. **Статус:** принято владельцем.

## Контекст

При проверке владелец заметил, что меню заголовка и кнопка настроек ничего не делают, скобки и кавычки не закрываются, а `println!` из дополнений вставляется без курсора внутри скобок. Ни одной из этих задач не было в ROADMAP.

## Решение

- Все четыре задачи взяты в этап 4.
- **Автозакрытие пар.** Логика лежит в `text` (`Document::insert_paired`, `delete_backward_paired`, тип `AutoPair`, `DEFAULT_PAIRS`) и работает на всех курсорах за один шаг отмены. Пары задаёт языковой пакет (`LanguagePack::with_pairs`, `LanguageEntry::pairs`). У Rust нет `'`, потому что с неё начинаются лайфтаймы. Выключается настройкой `[editor] auto_close_pairs`.

## Последствия

- Это аддитивные изменения публичного API крейтов `text` и `language`, согласованные с владельцем.
