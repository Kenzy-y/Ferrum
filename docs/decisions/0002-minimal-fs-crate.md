# 0002. Минимальный крейт `fs` на этапе 0

**Дата:** 2026-11-04. **Статус:** принято.

## Контекст

На этапе 0 нужно читать `settings.toml` и `keymap.toml`. По AGENTS.md доступ к файлам идёт только через трейт `Fs`, а крейт `fs` по плану появлялся на этапе 2.

## Решение

Крейт `fs` создан на этапе 0 в минимальном виде: трейт `Fs` с одной операцией `read_to_string`, которая возвращает `BoxFuture`, чтобы трейт оставался object-safe и пригодным для удалённой ФС, и реализация `RealFs`. Фейковая ФС, запись, обход каталогов и слежение за изменениями — задача этапа 2.

## Последствия

- `settings` читает файлы через `&dyn Fs`. `std::fs` вне крейта `fs` не используется.
- `RealFs` выполняет блокирующий ввод-вывод внутри future, поэтому его опрашивают только на фоновом executor.
