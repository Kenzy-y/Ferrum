# 0010. Встроенный терминал

**Дата:** 2026-11-07. **Статус:** принято владельцем (PTY, кнопки шапки); оформление списка терминалов, выбора оболочки и цвета ANSI ждут согласования.

## Контекст

Этап 6: терминал на `alacritty_terminal`, вкладки терминалов, выбор оболочки. В `editor.svg` есть шапка вкладки «Терминал» (оболочка ⌄, +, разделить, корзина, развернуть, закрыть), вывод шрифтом кода 13 px с шагом строк 24 px и подсказка «Toggle terminal / Command palette» в углу. Списка терминалов, меню оболочек и палитры ANSI в макетах нет.

## Решение

- **PTY** берётся из `alacritty_terminal` (ConPTY на Windows, openpty на Unix) — без новых зависимостей (выбор владельца). Запуск оболочки — `ProcessRunner::spawn_pty` в крейте `process`, поэтому `process` зависит от `alacritty_terminal`. Фейковый раннер PTY не создаёт: логику терминала тестируем, подавая байты в эмулятор.
- **Крейт `terminal`** (без GPUI): `TerminalSession` (поток чтения и эмуляции `alacritty_terminal`, события в UI с объединением пробуждений), `Snapshot` видимого экрана с готовыми цветами, `keys` (xterm-кодирование клавиш), `profiles` (поиск оболочек через `Fs`), настройки `[terminal]`.
- **Клавиши.** В фокусе терминала shell сначала прогоняет клавишу через keymap (фаза capture), кроме Ctrl/Alt с символом (Ctrl C, Ctrl R, Ctrl W) — они уходят программе, если их не привязал контекст `terminal`. Ctrl C при выделении копирует. Текст и IME идут через системный ввод.
- **UI** в `workbench/contrib/terminal`: все кнопки шапки по макету, включая разделение (терминалы рядом) и разворот панели на всю высоту области редактора (выбор владельца). При нескольких терминалах справа появляется список (`terminal_tabs.width`), выбор оболочки — меню под кнопкой.
- **Цвета:** `[terminal]` в теме; основной текст, курсор и зелёный — из макета, остальные ANSI подобраны по цветам синтаксиса.
- Смена папки проекта завершает оболочки прежней папки и запускает терминал в новой (запрос владельца).
- Закрытие последнего терминала скрывает панель; выход оболочки закрывает её терминал (`[terminal] close_on_exit`).

## Последствия

- Мышь в программах терминала (htop, vim с мышью) и ссылки пока не поддерживаются (ROADMAP).
- Для светлой и контрастной тем нужны свои `[terminal]`.
